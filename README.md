# Anthony Bolivar

CS + Math at Colgate University. First-gen from Texas. Currently studying abroad at Yonsei University in Seoul.

Recently, I've been exploring the limits of the **Roblox engine**.

Some things I've built:

* **EU4-Haven** · Reverse-engineering and tooling work around Europa Universalis IV, including native C++ integration, runtime hooks, and experimentation with the game's internals.
* **RISC-V Linux in Roblox** · An RV64 emulator written in Luau capable of booting Linux inside Roblox, with virtual memory, JIT execution, framebuffer and input devices, storage, package management, and networking.
* **Rocket Ball** · Multiplayer vehicle-soccer game built around server-authoritative physics, client prediction, reconciliation, interpolation, replay systems, matchmaking, and custom networking.
* **Shapes & States** · Voronoi-based political map generator with terrain-weighted pathfinding across a massive raster grid. Originally built as a D&D worldbuilding tool.

I write mostly **Python**, **C++**, **TypeScript**, and **Luau**.

I'm interested in systems, machine learning, reinforcement learning, reverse engineering, networking, simulation, and game technology.

Currently in **Seoul, South Korea · Yonsei University · Fall 2026**.
